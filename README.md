## Exercises

| # | Exercise | Concepts |
|---|---|---|
| 1 | Grade calculator | `if / else if / else`, logical operators |
| 2 | Drinks menu | `switch / case`, `break`, `default` |
| 3 | Running distance tracker | `for` loop, accumulator |
| 4 | Savings goal | `while` loop, counter |
| 5 | ATM simulator (PIN, balance, withdraw, deposit) | loops, nested conditions, booleans |

## Run Locally

```bash
git clone https://github.com/mo7-adad/test.git
cd test
```

Open `index.html` in your browser and check the output in the **Console** (F12).
